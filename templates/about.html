About This Project

This is a simple Python Flask web application created for DevOps CI/CD practice.

Technology Used

  • Python Flask for web application
  • HTML and CSS for frontend design
  • JavaScript for form validation
  • Ansible for build and deployment automation
  • Jenkins for CI/CD pipeline execution
  • Linux systemd service for running the application

Learning Purpose

This project helps students understand how developer code and DevOps automation work together in a real-world deployment flow.
