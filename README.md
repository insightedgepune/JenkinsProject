# Student Feedback App

This is a simple Python Flask web application created for Jenkins and Ansible deployment practice.

## Features

- Student feedback form
- Course selection
- Feedback display on same page
- About page
- Health check endpoint
- API endpoint for feedback
- CSS-based responsive UI
- JavaScript form validation

## Technology Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Jenkins
- Ansible
